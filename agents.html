Agent Squad: AI agents with bounds they can't argue with

Sixteen Claude Code agents with fixed roles that carry a ticket from investigation to a reviewed draft pull request, prove every step with evidence a script can check, argue against their own conclusions, and stop for a human only on exceptions. The core idea: don't ask an agent to behave; set its bounds outside the agent.

The enforcement ladder

Start at the top. Only move down when the rung above is impossible.

Separation of duties

The checker is never the maker

The tester writes failing contract tests first; the builder can only write application code. That's decided by file path on every write, so it isn't a request in a prompt.

Verify, don't trust

Evidence a script can check

The verifier re-runs every check itself, and its commands must appear in the harness's own transcript. A negative control proves the new tests fail on the old code.

Debate on evidence

A challenger with the opposite incentive

It steelmans, then attacks each claim with evidence that exists. Upheld counters send work back; after two rounds, a human decides.

Observability

An observer and efficiency metrics

A script replays every tool call from the transcripts (scope creep, workarounds, stale evidence), and an LLM judges what a script can't. Prompt changes only after a lesson recurs on two tickets.

Sixteen roles, each on the cheapest model that can do the job

    Status: the single-agent workflow this grew from took about 30 production tickets to review-ready pull requests, at least two a day. The full squad has run on one production ticket so far, side by side with that workflow. Its gates and guards are covered by more than 280 automated tests; model tiers and budgets are still first guesses until there's more history.
